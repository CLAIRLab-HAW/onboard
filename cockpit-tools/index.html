Watch over VNC

vnc://…:5900 copied

  • On a Mac: open the address in Screen Sharing, or in the terminal open vnc://…:5900. Other systems: the same address in a VNC viewer (Remmina, TigerVNC, RealVNC).
  • The viewer asks for a password. It is the container's VNC_PASSWORD, default husky (VNC passwords are limited to 8 characters by the protocol). The browser route over noVNC does not ask for it.
  • RViz comes up with the container (RVIZ_AUTOSTART=1) — so after the start, simply watch. Closing the RViz window leaves the container up; in the xterm, moveit-rviz starts it again.
  • Execute moves the real arm. To only look, stop at Plan, and clear the workspace beforehand.
  • With host networking this desktop sits directly on the robot's IP, and from inside it the arm can be operated. The 8-character password is a hurdle, not a protection — start it only in a trusted network and stop it again afterwards.
